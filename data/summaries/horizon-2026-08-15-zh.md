### 选题 1：官方 Claude Code 技巧：最大化会话价值

**关联新闻**: [官方 Claude Code 技巧：最大化会话价值](https://claude.com/blog/maximizing-the-value-of-your-claude-code-sessions)

**切入角度**: Anthropic 发布了 Claude Code 官方最佳实践指南，介绍提升会话效率和上下文管理的技巧，如用@提及文件、使用/context 命令以及管理上下文限制。 这份指南帮助开发者在 Claude Code 的上下文窗口内完成更多工作，减少中断和令牌浪费，直接影响 AI 辅助开发者的日常流程。 开发者评论指出了若干注意事项：@提及功能在桌面应用中存在故障（GitHub issue #71421），前缀缓存与 effort 设置绑定，可能效率不高。还有人质疑@提及大文件是否是反模式，因为它会读取整个文件，而不是像 Read 那样只读取相关部分。

**可延展方向**: Claude Code 是 Anthropic 推出的终端/IDE 代理式编码工具，能够理解代码库、编辑文件并运行命令。由于会话的上下文窗口有限，有效的上下文管理（如 compacting、/context 和文件引用）对于长时间运行的任务至关重要。Anthropic 还提供技能（skills）和插件来扩展 Claude Code 的功能。

## [“走向黑暗”时代重现：执法黑客技术遭遇极限](https://blog.cryptographyengineering.com/2026/08/14/everything-is-about-to-go-dark/) ⭐️ 8.0/10

2026 年 8 月 14 日发表在《密码学工程》博客上的一篇文章指出，一个“走向黑暗”的时代即将重现，因为执法部门依赖软件漏洞进行远程黑客攻击的能力正在接近实际极限。文章认为，当可用的漏洞供给越来越少时，对加密通信和设备的合法访问将变得越来越困难。 这一分析意义重大，因为它反驳了执法部门常见的“加密总能通过黑客手段绕过”的说法，并提出了监控能力可能下降的前景。其结果将影响未来围绕加密后门、执法部门黑客技术以及隐私与安全平衡的政策讨论。 文章的核心观点是，用于执法黑客行动（包括网络调查技术，NIT）的高价值软件漏洞是一种有限资源，可能很快就会触达“漏洞天花板”。文章也承认国家级黑客行动的高度复杂，同时指出，AI 生成的软件未必会产生更多可供合法访问使用的有效漏洞。

hackernews · vslira · 8月14日 20:52 · [社区讨论](https://news.ycombinator.com/item?id=49304447)

**背景**: “走向黑暗”（Going Dark）是执法部门的一个术语，指即便拥有合法授权也无法访问加密数据。自 1990 年代以来，美国法律通过《通信协助执法法案》（CALEA）要求电信运营商内置监听能力，但端到端加密和设备加密如今已使这种拦截难以实现。于是执法部门越来越多地转向“网络调查技术”——即通过钓鱼或路过式下载投递的政府恶意软件——尽管这类技术依赖于并不总是存在的软件漏洞。
