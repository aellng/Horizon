### 选题 1：OpenAI 发布 GPT-6 Sol 与 Luna，价格减半

**关联新闻**: [OpenAI 发布 GPT-6 Sol 与 Luna，价格减半](https://openai.com/index/introducing-gpt-6-sol-and-luna/)

**切入角度**: OpenAI 发布了 GPT-6 Sol 与 GPT-6 Luna 这一全新旗舰模型系列，即日起面向所有 Plus、Pro、Business、Enterprise 和 Edu 用户在 ChatGPT Work 与 Codex 中开放使用。6 系列模型的定价约为上一代 5.6 系列的一半，OpenAI 将这一降价归因于缓存与推理效率的改进。 对一线开发者而言，前沿模型价格减半的意义往往大于小幅能力提升，因为它直接决定了哪些常驻式 Agent 工作流和高并发应用在经济上可行。OpenAI 声称 GPT-6 模型“在成本—智能曲线上全面领先”，这也给 Anthropic 的 Claude 等竞争对手带来更大压力——用户已经开始把两者的编程 Agent 套餐逐项对比。 OpenAI 表示，在其内部事实准确性评测（基于用户标记出模型错误的匿名真实对话构建）中，GPT-6 Sol 的错误量约为上一代的一半，以低得多的成本达到了 Astra 级别的可靠性，同时编程任务的错误率也有所下降。官方明确将这些效率提升归功于缓存与推理优化，而非全新的底层架构，并且新模型层级目前仅在付费的 ChatGPT Work 与 Codex 套餐中提供。

**可延展方向**: GPT-6 Sol 与 Luna 是 OpenAI GPT 大语言模型（LLM）家族的最新成员。这类系统在海量文本语料上训练，逐 token 生成回答，如今还能驱动可调用工具的“Agent”，代替用户读取文件、运行代码并完成多步骤任务。在该家族内部，“Sol”“Luna”这类命名通常用于区分更强但更贵的模型与更便宜、更快的模型，而 OpenAI 对外强调的核心是“成本—智能曲线”，即每一美元能换来多少能力。Codex 是 OpenAI 面向编程的 Agent 产品，ChatGPT Work 则面向职场任务，二者正是新模型首批落地的入口。

### 选题 2：Anthropic 发布 Claude Opus 5.5，价格全面下调

**关联新闻**: [Anthropic 发布 Claude Opus 5.5，价格全面下调](https://www.anthropic.com/claude-opus-5-5)

**切入角度**: Anthropic 发布了新一代旗舰模型 Claude Opus 5.5，官方称其在多项能力上较前代有明显提升，并对 Claude Opus 5 全面降价。公告特别强调该模型在沟通与写作表达上的改进，早期测试者表示其文字更清晰、更易理解，也更适合长时间协作。 Claude Opus 5 据称是 OpenRouter 上支出最高的模型，因此能力提升与降价同时发生，可能改变大量开发者和重度 API 用户的成本考量。这次发布也带有争议性，因为 Anthropic 就在一周前还公开呼吁要"放慢前沿步伐"。 新定价为每百万输入 token 4 美元（原为 5 美元）、每百万输出 token 20 美元（原为 25 美元）、缓存读取 0.20 美元（原为 0.50 美元）、缓存写入 5 美元（原为 6.25 美元）。Anthropic 将更清晰的写作风格同时视为实用性和安全性上的收益，因为这样的输出更容易跟进和核查。

**可延展方向**: Claude Opus 是 Anthropic 旗下 Claude 模型家族中的最高端系列，面向最复杂的推理、编程与写作任务，并通过按每百万 token 计费的 API 对外销售。价格表中提到的提示缓存（prompt caching）可以让重复出现的上下文被存储和复用，从而降低长对话的运行成本。所谓"放慢前沿步伐"（pacing the frontier）指的是 Anthropic 近期公开主张以更谨慎、更克制的节奏开发最先进 AI 系统，批评者认为这与快速推出旗舰模型的做法相互矛盾。

### 选题 3：Claude Opus 5.5 评测引发定价与模型退化争论

**关联新闻**: [Claude Opus 5.5 评测引发定价与模型退化争论](https://artificialanalysis.ai/models/claude-opus-5-5)

**切入角度**: Artificial Analysis 发布了 Claude Opus 5.5 在三种推理强度设置（"max"、"xhigh" 以及默认的 "medium"）下的智能、性能与价格评测页面，相关内容随后被分享到 Hacker News 上。在讨论中，评论者 hglaser 指出，在同等高强度推理下，Opus 5.5 的每任务成本大约只有 Opus 5 的一半。 Claude Opus 5.5 属于头部闭源模型，其测得的每任务成本与智能评分会直接影响开发者和企业是继续为高额 API 付费，还是转向更便宜的替代方案。讨论中对"发布后性能退化"的担忧，以及对成本低得多却"够用"的开源权重模型的关注，折射出闭源实验室商业模式正面临的更广泛压力。 Artificial Analysis 为每个推理强度级别维护了独立页面，评论者 simonw 指出，"max" 设置下模型两次都未能生成所要求的"骑自行车的鹈鹕" SVG 图，原因是它在推理过程中耗尽了 128,000 token 的预算。他还给出了 xhigh 与 medium 各自的页面链接，说明不同推理预算下模型的结果差异可能相当大。

**可延展方向**: Artificial Analysis 是一个对大模型进行基准测试的网站，它会基于代码、终端任务和难题推理考试等一系列评测构建智能指数，并同时给出速度与每 token 价格等数据。Claude Opus 是 Anthropic 旗下的顶级闭源模型系列，而 "max/xhigh/medium" 指的是可配置的推理强度档位，档位越高消耗的思考 token 与成本越多，但可能得到更好的答案。开源权重模型是指训练后的参数被公开发布、任何人都可以下载并运行模型，与之相对的是只出售 API 访问权的闭源模型；DeepSeek、阿里云 Qwen、Moonshot AI 和 Z.ai 等中国实验室是其中最活跃的开源权重发布方。
